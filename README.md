# Тамагочи

Учебное Android-приложение на Kotlin + Jetpack Compose. Один экран с питомцем.

## Что есть
- `Pet.kt` — неизменяемая модель питомца (сытость, энергия, счастье, здоровье) и действия: `feed()`, `play()`, `sleep()`, `tick()`.
- `PetScreen.kt` — экран: эмодзи-настроение, полоски показателей, три кнопки. Раз в 5 секунд срабатывает тик времени.
- `PetTest.kt` — юнит-тесты на модель.

## Запуск
Открыть в Android Studio и нажать Run, либо:

```bash
./gradlew assembleDebug
```
